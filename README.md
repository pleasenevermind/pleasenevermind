# pleasenevermind

I build AI agent systems and on-chain products, mostly in TypeScript.

## What I work on

- **Agents.** Planning loops, tool calling, evaluation harnesses, tracing, and the sandboxing and permission work that keeps tool use from going sideways.
- **Web3.** Trading terminals, launchpads, tokenized assets, wallet flows. EVM chains and the TypeScript around them.
- **Product.** Next.js and React front ends, TypeScript end to end. Landing pages through to the app behind them.
- **Experiments.** Unreal/Lyra C++ templates, Swift/macOS utilities, federated learning notebooks.

## Public work

- [dev-log](https://github.com/pleasenevermind/dev-log): working notes on agent evals, retrieval, local inference, MCP security, and on-chain indexing.
- [Repositories](https://github.com/pleasenevermind?tab=repositories)

Most of my work lives in private repos. `dev-log` is the public trail: what I tried, what broke, and what I would do next.
